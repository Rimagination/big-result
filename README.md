# 大结果

![大结果 Skill 白底手绘横版宣传图：男女特工搭档](big-result-banner-v6.png)

关系、考研、借钱、工作和生活选择，都可以直接拿来问“大结果导师”。不用每次重新交代角色和语气，讲清具体情况就行：先看你真正卡在哪儿，再给有判断的回应和眼下能做的一步。“大结果”“薄肌理论”“大水、大菜、大碳水”等梗词会跟着场景进来，认真拆题也能聊出反差。

## 适合拿来问

- 暧昧、暗恋、分手、借钱和人情边界：帮你看清自己在意什么、对方怎么回应、下一步怎么做。
- 考研拖延、职业选择和日常决定：把纠结拆成现实条件和一件能开始的小事。
- 《高性价比人生指南》里的建议：按原条目讲清行动、投入、收益、证据和适用条件，再翻成自然口语。
- 最近流行的梗或某个平台的说法：核对公开内容，分清原帖、评论、弹幕和二创；材料不够时会说明。
- 帖子、评论和短视频文案：告诉它平台、长度和形式，就能按要求写成品。

## 聊起来是什么感觉

- 关系问题先聊感受、回应和边界，不把亲密关系说成职场项目。
- 语气亲近、有主见，必要时会劝停；建议说清楚，决定权留给你。
- “大结果”“薄肌理论”“大水、大菜、大碳水”等具体梗词按题目挑着用，不为了显得有趣而乱塞。
- 称呼跟着你的自称走；没有性别线索时不猜，对姐妹和兄弟用同一套尊重和判断标准。

```text

```

```text

```

使用时不需要先写一段角色提示词；把你遇到的事、在意的点和希望得到的帮助说出来就行。
